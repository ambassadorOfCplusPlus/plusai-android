# Plus AI (Android)

Мультиплатформенный ИИ-агент — мобильный клиент. Не чат-бот, а агент: сам находит документы, пишет и запускает код, работает с файлами, почтой, календарём, SSH, Git. Локально (llama.cpp) + облако.

## Возможности

- **140+ инструментов**: файлы, PDF/Word/Excel/PPTX, Python (pandas, matplotlib, torch), JS/TS/Lua/Java/Kotlin/C/Shell, браузер/WebView, HTTP, SSH, Git, SQLite, QR, email, календарь, SMS, NFC, камера
- **Локальные модели**: 62 GGUF (Gemma 4 E2B, Phi-4 Mini, Llama 3.2, Qwen2.5, SmolLM2) — качаются из HuggingFace
- **Видение**: SmolVLM2 500M — описание фото/видео на устройстве
- **RAG**: bge-m3 эмбеддер, семантический поиск по документам
- **ПК-режим**: телефон ↔ десктоп через E2E-релэй (ECDH + AES-256-GCM)
- **Бета-режим**: DeepSeek V4 Flash + Qwen Next бесплатно

## Сборка

Требуется Android SDK, NDK, Python (Chaquopy). Сборка:

```bash
./gradlew assembleDebug
```

APK выходит в `app/build/outputs/apk/debug/app-debug.apk`.
